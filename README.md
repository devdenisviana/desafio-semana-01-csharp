## 📝 Exercícios

### Exercício 1 - Apresentação Pessoal
Programa que exibe informações pessoais no console.

**Conceitos praticados:** Variáveis, `Console.WriteLine()`

**Saída esperada:**
```
Nome: Denis
Idade: 46
Cidade: Fortaleza
Profissão dos sonhos: Desenvolvedor Backend
```

---

### Exercício 2 - Cadastro de Produto
Programa que armazena e exibe informações de um produto.

**Conceitos praticados:** Variáveis, tipo `decimal`, formatação de números com `ToString("F2")`

**Saída esperada:**
```
Produto: Teclado Mecânico
Preço: R$ 250,00
Quantidade: 15
```

---

### Exercício 3 - Calculadora Simples
Programa que realiza as quatro operações aritméticas entre dois números.

**Conceitos praticados:** Operadores aritméticos (`+`, `-`, `*`, `/`)

**Saída esperada:**
```
10 + 5 = 15
10 - 5 = 5
10 * 5 = 50
10 / 5 = 2
```

---

### Exercício 4 - Verificador de Idade
Programa que verifica se uma pessoa é maior ou menor de idade.

**Conceitos praticados:** Operadores relacionais, operador ternário

**Saída esperada:**
```
Maior de idade
```

---

### Exercício 5 - Primeira Função
Programa que utiliza funções para exibir mensagens e calcular a média de três notas.

**Conceitos praticados:** Métodos/Funções, parâmetros, retorno de valores

**Saída esperada:**
```
Estou aprendendo C# e criando minhas primeiras funções!
Nota 1: 8
Nota 2: 7
Nota 3: 9
Média: 8
```

---

## 🔥 Desafio Bônus - Função CalcularMedia
Função que recebe 3 notas como parâmetros e retorna a média aritmética.
